
# Cambios recientes en la estacionalidad climática en México (1974–2023)

Este repositorio contiene los datos y scripts utilizados para el análisis de la estacionalidad de la precipitación en México, enfocándose en las tendencias de inicio (*onset*), término (*offset*) y duración de la temporada de lluvias.

## 📊 Fuente de Datos

* **Dataset:** Climatic Research Unit (CRU) Time Series (TS) dataset versión 4.08.
* **Cobertura temporal:** 1901–2023 (Periodo de análisis principal: 1974–2023).
* **Referencia:** Harris, I., Jones, P.D., Osborn, T.J. et al. (2020/2023).

## 📁 Estructura del Repositorio

├── datos/ # Archivos CSV y grillas procesadas (ej. precipitacionMexico.csv)
├── scripts/ # Código de procesamiento y análisis en R
└── outputs/ # Gráficas, mapas y tablas generadas

## 🛠️ Requisitos

* **R** (versión >= 4.0)
* Paquetes de R: `raster`, `ncdf4`,`dplyr`
